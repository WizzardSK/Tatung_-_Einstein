# Tatung_-_Einstein

Thumbnails for Tatung Einstein software, laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails) (`Named_Snaps`), named after the MAME short names, as the MAME `einstein` software list has them.

The snaps were taken with the MAME libretro core in RetroArch: each disk boots XtalDOS, the name of its first `.COM` program is typed in, and MAME takes a snapshot every 300 frames from frame 900 to 2700; the one with the most colours is kept, at twice the machine's height (576x432). Without a player the games stay on their title screen or demo, which is what the snaps show. Disks without a `.COM` program (BASIC programs) and games that stayed blank have no snap.
